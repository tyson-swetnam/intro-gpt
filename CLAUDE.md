# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## Project Overview

This is a documentation website built with Zensical (the next-generation static site generator by the Material for MkDocs team) for a "GPT 101" workshop on AI prompt engineering. The site provides educational content on generative AI, prompt engineering, and AI tools for academic research and education.

## Development Commands

### Setup and Installation
```bash
pip install -r requirements.txt
```

### Development Server
```bash
zensical serve
```
This starts a local development server with live reload for content changes.

### Building the Site
```bash
zensical build
```

## Project Structure

- `docs/` - All markdown content and assets for the website
- `zensical.toml` - Main configuration file defining site structure, theme, and plugins
- `requirements.txt` - Python dependencies for Zensical and plugins
- `site/` - Generated static site output (created by `zensical build`)

## Key Configuration

The site is configured in `zensical.toml` with:
- Material theme with custom University of Arizona branding
- Navigation structure covering AI landscape, setup guides, prompt engineering, education, research, and ethics
- Multiple markdown extensions for enhanced formatting (admonitions, code highlighting, emoji, etc.)
- Google Analytics integration
- Zensical plugins: mkdocstrings (preliminary support), search (built-in)

## OKF Frontmatter (required on every page)

`docs/` is an [Open Knowledge Format v0.2](https://github.com/GoogleCloudPlatform/knowledge-catalog/blob/main/okf/SPEC.md) bundle. Every markdown page carries YAML frontmatter in this exact key order (`okf_version: "0.2"` first on `docs/index.md` only):

```yaml
---
type: Setup Guide            # taxonomy: Index, Overview, Setup Guide, Prompting Guide,
                             # Education Guide, Research Guide, Ethics Guide, Tutorial, Log
title: OpenAI ChatGPT        # H1 text with icon shortcodes stripped
description: >-              # 50-160 chars plain text; becomes meta description + llms.txt entry
  One to two concrete sentences about this page.
resource: https://tyson-swetnam.github.io/intro-gpt/chatgpt/   # canonical directory URL
tags: [setup, openai, pricing]   # 1-6 from the vocabulary in scripts/validate_okf.py
sources:                     # 3-8 load-bearing external links from the page body; omit if none
  - resource: https://openai.com/api/pricing/
    title: OpenAI API pricing
generated:
  by: human:tswetnam
  at: "2026-05-10T19:02:57Z" # ISO-8601, always quoted
verified:
  - by: human:tswetnam      # human-only; automation must never add verified entries
    at: "2026-05-10T19:02:57Z"
status: stable
stale_after: "2026-11-01T00:00:00Z"   # only pricing-bearing pages; 6 months past verification
---
```

Conventions:
- `scripts/validate_okf.py` is the source of truth for the type taxonomy and tag vocabulary; run `python3 scripts/validate_okf.py docs` before committing (CI enforces it).
- New pages must also be linked from the `docs/index.md` "Workshop Sections" listing and noted in `docs/log.md` (newest-first `## YYYY-MM-DD` headings with `**Creation**`/`**Update**` bullets).
- `docs/log.md` is the OKF-reserved change log; keep it out of nav.

## Agent-Readable Publishing

CI (`.github/workflows/main.yml`) publishes, beyond the rendered HTML:
- Raw markdown sources as siblings of each page (`/chatgpt/` ↔ `/chatgpt.md`), via a post-build rsync.
- `llms.txt` + `llms-full.txt` generated by `scripts/generate_llms_txt.py` from nav + frontmatter.
- Per-page JSON-LD, OG tags, and a `text/markdown` alternate link injected by `overrides/main.html` (MiniJinja; autoescape is OFF — use `| e` for attributes, `| tojson` for JSON-LD scalars).

Local reproduction of the full pipeline (plain `zensical` is not on PATH; scripts need Python ≥3.11 + PyYAML):

```bash
rm -rf site && uvx --with mkdocs-material --with mkdocstrings-python zensical build
rsync -a --prune-empty-dirs --exclude='.#*' --exclude='#*#' --exclude='*~' --exclude='.DS_Store' \
  --include='*/' --include='*.md' --exclude='*' docs/ site/
uv run --no-project --python 3.11 --with pyyaml scripts/generate_llms_txt.py
uv run --no-project --python 3.11 --with pyyaml scripts/validate_okf.py docs
```

## Content Guidelines

Documentation covers five main areas:
1. **Setup** - Instructions for various AI platforms (ChatGPT, Claude, Gemini, etc.)
2. **Prompt Engineering** - Core techniques and productivity applications  
3. **Education** - AI integration in teaching and learning
4. **Research** - AI applications in academic research
5. **Ethics** - Responsible AI use and considerations

The site includes interactive tutorials and case studies in the `tutorials/` subdirectory.
